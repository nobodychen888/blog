## 🚀 安装 V2Board（旧版 1.7.3）

### 1️⃣ 安装 aaPanel 面板

```bash
URL=https://www.aapanel.com/script/install_panel_en.sh && if [ -f /usr/bin/curl ];then curl -ksSO $URL ;else wget --no-check-certificate -O install_panel_en.sh $URL;fi;bash install_panel_en.sh ipssl
```

### 面板环境选择：

* ☑️ Nginx 1.30
* ☑️ MySQL 5.7
* ☑️ PHP 8.3

选择：**Fast（快速编译安装）**

---

### 2️⃣ 安装 PHP 扩展

路径：

```
aaPanel 面板 > 应用商店 > 已安装 > PHP 8.3 > 设置 > Install Extensions
```

安装以下扩展：

* redis
* fileinfo

---

### 3️⃣ 解除 PHP 禁用函数

路径：

```
PHP 8.3 设置 > Disabled Functions
```

删除以下函数：

```
putenv
proc_open
pcntl_alarm
pcntl_signal
```

---

### 4️⃣ 添加站点

```
aaPanel 面板 > 网站 > 添加站点
```

操作：

1. 创建站点
2. 进入站点目录
3. 删除目录内所有文件（删除两次，确保完全清空）

---

### 5️⃣ 安装 V2Board

#### 下载源码：

```bash
wget https://github.com/v2board/v2board/archive/refs/tags/1.7.3.tar.gz
tar -zxvf 1.7.3.tar.gz
```

#### 进入目录执行安装：

```bash
cd v2board-1.7.3
sh init.sh
```

---

### 6️⃣ 配置站点目录 & 伪静态

#### 📁 网站目录：

```
/public
```

#### 🔧 Nginx 伪静态配置：

```nginx
location /downloads {
}

location / {  
    try_files $uri $uri/ /index.php$is_args$query_string;  
}

location ~ .*\.(js|css)?$
{
    expires      1h;
    error_log off;
    access_log /dev/null; 
}
```

---

### 7️⃣ 配置定时任务

路径：

```
aaPanel 面板 > 计划任务
```

配置如下：

* 类型：Shell 脚本
* 名称：v2board
* 周期：每 1 分钟
* 用户：www
* 脚本内容：

```bash
php /www/wwwroot/你的站点路径/artisan schedule:run
```

---

### 8️⃣ 启动队列服务（Supervisor）

安装路径：

```
aaPanel > 应用商店 > 搜索 supervisor
```

添加守护进程：

* Name：V2board
* Run User：www
* Run Dir：站点目录
* Start Command：

```bash
php artisan horizon
```

* Processes：1

点击 **Confirm** 启动

---
