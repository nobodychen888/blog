# V2Board 搭建与升级完整教程

# Youtube操作视频：https://youtu.be/fUFqeDKoJrA

## 一、安装 V2Board

### 1. 前期准备

* 准备一台 VPS（推荐系统：Ubuntu 22.04）
* 使用 SSH 登录 VPS
* 申请一个域名，并在 Cloudflare 添加 A 记录解析到服务器 IP

---

### 2. 安装 aaPanel 面板

```bash
URL=https://www.aapanel.com/script/install_panel_en.sh && if [ -f /usr/bin/curl ];then curl -ksSO $URL ;else wget --no-check-certificate -O install_panel_en.sh $URL;fi;bash install_panel_en.sh ipssl
```

---

### 3. 配置运行环境

在 aaPanel 中安装以下组件：

* Nginx 1.30
* MySQL 5.7
* PHP 8.3

---

### 4. 安装扩展

安装以下 PHP 扩展：

* Redis
* fileinfo

---

### 5. 解除 PHP 禁用函数

路径：

> aaPanel 面板 → 应用商店 → 已安装 → PHP 8.3 → 设置 → Disabled functions

删除以下函数：

```
putenv
proc_open
pcntl_alarm
pcntl_signal
```

---

### 6. 添加网站

配置如下：

* **Domain**：填写解析到服务器的域名
* **数据库**：选择 MySQL
* **PHP版本**：选择 PHP 8.3

---

### 7. 安装 V2Board


1、删除网站目录下的所有文件
2、通过 cd+路径，进入文件夹目录
3、克隆项目到根目录下
```bash
git clone https://github.com/v2board/v2board.git ./
```
4、安装
```bash
sh init.sh
```

---

### 8. 配置伪静态（Nginx）

```bash
location /downloads {
}

location / {  
    try_files $uri $uri/ /index.php$is_args$query_string;  
}

location ~ .*\.(js|css)?$
{
    expires      1h;
    error_log off;
    access_log /dev/null; 
}
```

---

### 9. 配置定时任务

路径：

> aaPanel 面板 → 计划任务

配置如下：

* **任务类型**：Shell 脚本
* **任务名称**：v2board
* **执行周期**：每 1 分钟
* **执行用户**：www
* **脚本内容**：

```bash
php /www/wwwroot/你的站点路径/artisan schedule:run
```

---

### 10. 启动队列服务（Supervisor）

安装路径：

> aaPanel → 应用商店 → 搜索 Supervisor → 安装

添加守护进程：

* **Name**：V2board
* **Run User**：www
* **Run Dir**：站点目录（例如 `/www/wwwroot/yourdomain.com`）
* **Start Command**：

```bash
php artisan horizon
```

* **Processes**：1

点击 Confirm 启动即可。

---

## 二、升级分支（推荐）

### 仓库地址

```
https://github.com/wyx2685/v2board
```

---

### 1. 安全检查

```bash
git config --global --add safe.directory /www/wwwroot/你的站点目录
```

---

### 2. 切换仓库并更新

```bash
git remote set-url origin https://github.com/wyx2685/v2board
git checkout master
./update.sh
```

---

### 3. 配置缓存并重启服务

```bash
sed -i 's/^CACHE_DRIVER=.*/CACHE_DRIVER=redis/' .env
php artisan config:clear
php artisan config:cache
php artisan horizon:terminate
```

---

### 4. 后台操作

进入 V2Board 后台：

> 主题配置 → 选择 default → 主题设置 → 保存

---
